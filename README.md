## 📖 About The Project

This is not just a portfolio; it is a **fully interactive web-based operating system**. 

Designed by **Porosh Islam Tarek**, a Senior Full-Stack Developer, this project bridges the gap between creativity and engineering. It abandons traditional scrolling layouts for a window-based desktop environment, featuring a Neo-Brutalist aesthetic, complex physics simulations, 3D rendering, and a real-time AI assistant.

It showcases mastery over **Frontend Architecture**, **State Management**, **WebGL**, and **Generative AI integration**.

---

## 🧩 System Architecture & Tech Stack

This "OS" runs entirely in the browser, optimized for both high-end desktops and mobile devices.

- **Core:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS (Neo-Brutalist Design System)
- **State Management:** Zustand (Window Manager, Theme, Process State)
- **Animations:** Framer Motion (Transitions, Physics, layoutID)
- **3D Engine:** Three.js (Solar System, Shaders, Particle Systems)
- **Window Management:** React-Rnd (Draggable/Resizable windows)
- **AI Integration:** Google Gemini 2.5 Flash (Context-aware Chatbot)
- **Services:** EmailJS (Contact), Google Maps (Geolocation)

## 🛠️ Installed Applications (Features)

The OS comes pre-installed with a suite of functional applications demonstrating various engineering skills:

### 🧠 Intelligence & Core
*   **🤖 Emma Chan (AI Assistant):** A fully context-aware AI agent powered by Google Gemini. "Emma" knows Porosh's entire resume and portfolio and answers visitor questions in real-time.
*   **💻 Terminal:** A Zsh-style command-line interface. Supports commands like `sudo`, `grep`, `whoami`, and even runs a full **Snake Game** inside the shell.
*   **⚙️ System Architecture:** An interactive diagram visualizer explaining frontend, backend, and infrastructure layers.

### 🎨 Creativity & UI/UX
*   **🌌 Universe (PixelVerse):** A WebGL solar system simulation using custom GLSL shaders for the Sun, planetary atmospheres, and black holes.
*   **🧪 Experimental Lab:** A sandbox for R&D. Includes Gravity physics engines, Sorting Algorithm visualizers, Fluid dynamics, and 3D UI cards.
*   **🎨 Theme Settings:** Full system personalization. Switch between Light/Dark modes, change accent colors, and modify desktop wallpapers.

### 📂 Professional Data
*   **📄 Resume:** Integrated PDF viewer with print and download capabilities.
*   **💼 Projects:** A filtering-enabled grid of case studies with expandable details and GitHub/Live links.
*   **🧠 Reasoning:** Detailed breakdowns of engineering problems, trade-offs, and solutions (Case Studies).
*   **📝 Blog:** A CMS-style feed for reading technical articles.

### 🎮 Interactive
*   **🕹️ Arcade:** A suite of mini-games (Memory, Speed Math, Reaction Test, Pattern Match) to demonstrate state complexity handling.
*   **📍 Mission Map:** Google Maps integration showing the developer's HQ.
*   **📫 Contact Hub:** A working email client integrated with EmailJS for direct communication.

## 🚀 Getting Started

To run this operating system locally on your machine:

### Prerequisites
*   Node.js (v18 or higher)
*   npm or yarn

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/taanzzz/portfolio-os.git
    cd portfolio-os
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Configure Environment Variables:**
    Create a `.env` file in the root directory. You need keys for the AI Chatbot and Contact Form to work fully.
    ```env
    # Google Gemini API Key (Required for Chatbot)
    API_KEY=your_google_genai_api_key

    # Note: EmailJS keys are currently hardcoded in ContactApp.tsx 
    # but should ideally be moved here for production.
    ```

4.  **Boot the System (Run Dev Server):**
    ```bash
    npm run dev
    ```

5.  **Build for Production:**
    ```bash
    npm run build
    ```
